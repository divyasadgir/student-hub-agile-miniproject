# StudentHub – Student Record and Academic Management Platform

A responsive front-end MVP created for the UNIT-2 Agile Mini Project.

## Features
- Dashboard with student, course, attendance and marks counts
- Add, search and delete student records
- Add and delete courses
- Record and view attendance
- Enter marks and calculate a simple grade
- Export all stored data as JSON
- Responsive layout for desktop and mobile

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Add students and courses, then record attendance and marks.

No installation or server is required.

## GitHub Pages deployment
1. Create a public GitHub repository named `studenthub-agile-mini-project`.
2. Upload `index.html`, `style.css`, `script.js`, and this README.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Wait for the Pages URL to appear.

## Important limitation
This is an educational MVP. Data is stored in the current browser using Local Storage. It is not a multi-user cloud database and does not provide production-grade authentication or security. Do not enter real or confidential student data.

## Technology
HTML5, CSS3, JavaScript, Browser Local Storage.

## Agile scope
The project demonstrates Student Management, Course Management, Attendance Management, Marks & Academic Performance, and basic Reporting through a small working prototype.
